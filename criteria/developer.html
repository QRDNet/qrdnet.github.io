QRDNet Certified Developer

This developer level certifies the ability to build quantum algorithms, hardware simulations using Verilog, Python, or Rust, and software CI pipelines.

Examination Criteria:

  • Implement a quantum circuit or hardware component using Python, Rust, Verilog, or a similar language.
  • Write automated unit tests and complete a successful CI run.
  • Follow Open Source licensing requirements, such as MIT or CERN OHL v2, in the codebase.
